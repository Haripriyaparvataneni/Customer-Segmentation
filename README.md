# Customer Segmentation (RFM + K-Means)

Portfolio demo project: RFM analysis and K-Means customer segmentation on
synthetic retail transactions. **All data is synthetic** (generated by
`data/generate_data.py`) — this is a portfolio demonstration, not tied to
any employer or real customer data.

## What it does

- Generates ~1 year of synthetic transactions for 1,000 customers, mixing
  four archetypes (loyal regulars, big spenders, new customers, lapsed).
- Computes **RFM features**: Recency (days since last purchase),
  Frequency (order count), Monetary (total spend).
- Runs **K-Means** over scaled RFM features, selects `k` with an elbow
  heuristic, profiles each cluster, and assigns business-friendly labels
  (e.g. "Champions", "At Risk").
- Saves matplotlib visualizations to `figures/`.

## Project structure

```
customer-segmentation/
├── data/
│   └── generate_data.py     # synthetic transaction generator
├── src/
│   ├── rfm.py               # Recency/Frequency/Monetary feature builder
│   ├── cluster.py           # K-Means + elbow selection + cluster labels
│   └── visualize.py         # RFM histograms + 2D segment scatter
├── figures/                 # generated plots (created by visualize.py)
├── requirements.txt
└── .gitignore
```

## How to run

```bash
python -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt

# 1. Generate synthetic transactions
python data/generate_data.py

# 2. Build RFM features
python src/rfm.py

# 3. Cluster, profile, and label segments
python src/cluster.py

# 4. Generate plots
python src/visualize.py
```

## Clusters found

From an actual run (elbow selected **k=4**):

| Segment | Size | Avg Recency (days) | Avg Frequency | Avg Monetary ($) |
|---|---|---|---|---|
| Champions | 294 | 23.3 | 18.4 | 1,113.70 |
| New Customers | 322 | 41.3 | 4.2 | 315.50 |
| At Risk | 146 | 45.5 | 7.2 | 1,586.00 |
| Hibernating | 238 | 169.6 | 6.3 | 496.60 |

- **Champions** — recent, frequent, high-spend: reward and retain.
- **New Customers** — recent but few orders: nurture into repeat buyers.
- **At Risk** — high historical spend but drifting: win-back campaigns.
- **Hibernating** — long inactive: low-priority re-engagement.
